## 🚀 About Me

I am a Data Science Undergraduate at the **Department of Data Science, Faculty of Computing, Sabaragamuwa University of Sri Lanka (SUSL)**. My work focuses on the intersection of **AI & Multi-Agent Systems**, **Predictive Machine Learning**, **Business Intelligence**, and **Full-Stack Application Development**.

- 🎓 **Education**: BSc (Hons) in Data Science, Sabaragamuwa University of Sri Lanka (**CGPA: 3.7 / 4.0**)
- 💼 **Experience**: Digital Service Assistant at **Commercial Bank of Ceylon** & IT Consultant at **Dharmavijaya Computer Training School**
- 🧠 **Core Interests**: Multi-Agent State Machines (LangGraph), DistilBERT NLP, Power BI & DAX, Serverless AWS Cloud Pipelines, Time-Series & Quantitative Risk Modeling
- 🏆 **Hackathons**: 2nd Runner-up @ CodeMania v6.0 | Finalist @ CryptX 2.0, BitCode 6.0, Cipher 2.0, BioFusion 2025

## 💻 Portfolio Application Setup

This portfolio is built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**.

### Run Locally:
```bash
# Clone the repository
git clone https://github.com/sankajithdjinasena/Portfolio.git

# Navigate into project directory
cd Portfolio

# Install dependencies
npm install

# Start Vite development server
npm run dev
```

### Production Build:
```bash
npm run build
```
